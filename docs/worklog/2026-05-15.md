## Thoughts

The compute and load_balancer handlers already had the correct patterns — I followed those exactly for consistency. The terraform handler was the most behind (no auth checks, no tenantId, no label stamping). The `xrBelongsToTenant` helper consolidates the matching logic that was duplicated between `computeInstanceBelongsToTenant` and `loadBalancerBelongsToTenant` — didn't refactor those existing ones (YAGNI), but new resource types use the shared helper.

MCUCP-191 (RBAC) still needs implementation. It depends on these tenant labels being in place first.
