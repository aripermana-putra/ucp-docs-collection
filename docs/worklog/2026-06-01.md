## What I thought

The cloud provider authz model analysis forced a clearer articulation of what UCP actually is: a control plane that abstracts away provider differences including authorization. Splitting credentials to mirror provider-level access control contradicts that goal entirely.

Option 1B (OC service roles cross-provider) is the most elegant path — the data is already there from the JWT, the OC model is one tenants already understand, and it naturally extends to any cloud provider UCP supports. The main open question is whether we need that granularity at MVP at all, which is a PM call.
