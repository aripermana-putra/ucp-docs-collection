# Japanese Study Plan — Beginner

A self-paced plan for learning Japanese from scratch using Dr. Moku and Genki I (2nd edition).
Designed to be used independently — hand this to anyone starting from zero.

---

## What You Need

| Item | Purpose |
|------|---------|
| Dr. Moku app (iOS/Android) | Learning kana using mnemonics |
| Genki I textbook (2nd edition) | Main Japanese course |
| Genki I workbook (2nd edition) | Practice exercises |
| Genki audio files | Dialogue and listening (companion site or app) |
| Anki (free, desktop + mobile) | Spaced repetition for long-term vocabulary retention |
| Notebook + pen | All writing practice — no shortcuts here |

---

## How to Use This Plan

This plan has two independent tracks:

- **Kana Track** — 20 min per session. Learn to read and write all Japanese characters (hiragana + katakana).
- **Genki I Track** — 40 min per session. Work through Genki I chapter by chapter.

**In a 60-min study day:** complete one session from each track.
**Tracks are independent.** If you skip a Genki session but do kana, just check off kana and continue. Each track has its own checklist. Pick up wherever the last checkmark ends.

You can repeat any session by unchecking and redoing it. There is no penalty for going slow.

**Daily Anki (outside the 60-min sessions):** Do Anki reviews every day, even on days you skip the main sessions. 10–15 min is enough. Anki handles long-term vocabulary retention automatically — it shows you cards right before you are about to forget them. Without this, vocabulary from earlier chapters will fade by the time you reach later ones. See the [Anki Setup](#anki-setup) section.

**Review cadence built into the Genki track:**
- After every chapter: one chapter review session (GR)
- After every 3 chapters: one cumulative review session (GC) covering all grammar learned so far

---

## Note for Early Sessions

Genki I uses hiragana throughout. Since you are learning hiragana and Genki simultaneously, early Genki sessions will be harder to read. Use the furigana (small readings printed above characters) in the textbook as a crutch. As your kana improves session by session, you will rely on furigana less and less. By the time you finish the kana track, you should be reading hiragana directly.

---

## Anki Setup

Anki is a free flashcard app that uses spaced repetition — it automatically schedules cards so you review them right before you would forget them. This handles long-term retention across all 12 chapters without you having to manage it manually.

**Install:** [ankiweb.net](https://apps.ankiweb.net) (desktop) + AnkiDroid (Android) or AnkiMobile (iOS)

**Get the Genki I deck:**
1. Go to [ankiweb.net/shared/decks](https://ankiweb.net/shared/decks)
2. Search "Genki I" — use a deck that includes vocabulary for all 12 chapters
3. Download and import it into Anki

**Daily routine (outside your 60-min sessions):**
- Do all due reviews every day — takes 5–15 min depending on how many cards are due
- As you complete each Genki chapter, unsuspend (activate) the cards for that chapter so new vocabulary enters your review queue
- Do not add cards for chapters you haven't studied yet

**Settings to configure:**
- New cards per day: 10–15 (manageable without overwhelming)
- Reviews per day: 100+ (let Anki show everything that's due)

You do not need to create your own cards — the pre-made Genki deck has everything.

- [ ] **[10 min] Learn A row — Dr. Moku**

  | Kana | Romaji |

  | う | u |
  | え | e |

  Open Dr. Moku. Learn each character using the mnemonic. Trace each one 10× in your notebook.

## How Each Genki Session Works

**Dialogue + Vocabulary session (40 min):**
1. [5 min] Play dialogue audio with book closed. Try to catch any words you know.
2. [5 min] Read the dialogue with book open. Note unknown words.
3. [5 min] Read the dialogue aloud 3× until pronunciation flows naturally.
4. [15 min] Study vocabulary list: say each word aloud, write kana 2× in notebook, write English meaning.
5. [10 min] Self-test: cover kana column → produce Japanese from meaning. Cover meaning → produce English from kana. Write misses 3×.

**Grammar Notes session (40 min):**
For each grammar note covered in the session, complete the full loop before moving to the next note:
1. Read the grammar note carefully.
2. Write all example sentences from the note into your notebook (both Japanese and English).
3. Write 3 original sentences using the pattern.
4. Do all textbook exercises for that grammar note. Check answers. Write wrong answers 3×.
5. Do the corresponding workbook exercises for that grammar note. Check answers. Write wrong answers 3×.

Workbook exercises are split across sessions — do them right after the grammar note they correspond to, while it is still fresh.

## Chapter Review Format (GR sessions)

**Every chapter review session = 40 min. No textbook needed — pure recall.**

- [ ] **[10 min] Vocabulary recall**
  Without opening the textbook, write as many words from this chapter as you can remember — kana and meaning. When time is up, open the vocab list and check. Add anything you missed to Anki immediately.

- [ ] **[20 min] Grammar recall**
  For each grammar point in the chapter, write 2 original sentences from memory without referring to your notes. If you blank on a grammar point, mark it — re-read that note before the next session.

- [ ] **[10 min] Re-do weak spots**
  Re-do any workbook exercises you got wrong in the chapter sessions. If all were correct, pick the grammar point you felt least confident on and write 3 more original sentences.

## Cumulative Review Format (GC sessions)

**Every cumulative review session = 40 min. No textbook needed — pure recall.**

The goal is not to re-study everything. It is to surface what is weak so you know what needs more attention.

- [ ] **[30 min] Grammar sweep**
  Go chapter by chapter through everything covered so far. For each chapter, write one sentence using one grammar point from that chapter — from memory, no notes.
  Keep a list of any chapter/grammar point you blank on or feel shaky about.

- [ ] **[10 min] Target weak spots**
  For each grammar point you blanked on: open your notebook, re-read your example sentences for that point, then write 2 new sentences. Do not re-read the textbook note — just your own notes. If your own notes are not enough, flag it for a full re-read next session.
